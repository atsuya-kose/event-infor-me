# おでかけイベント(杉並・世田谷・吉祥寺 / 東京 / 関東近郊)

家族で行けるイベントをまとめた静的サイトです(GitHub Pagesで公開)。毎日更新します。

## 表示の区分
エリア3種 × 期間2種の6区分で絞り込めます。

| | 直近1週間 | 1週間以上先 |
|---|---|---|
| 杉並・世田谷・吉祥寺周辺 | ○ | ○ |
| 東京都内 | ○ | ○ |
| 関東近郊 | ○ | ○ |

期間は日付から自動判定されます。終了日を過ぎたイベントは自動で非表示になります。

## 構成
- `index.html` … 表示ページ
- `events.js` … イベントデータ。**更新するのはこのファイルだけ**
- `UPDATE.md` … 毎日更新の手順(掲載方針・ルール)

## 公開方法(GitHub Pages)
1. リポジトリの Settings → Pages
2. Source: `Deploy from a branch` / Branch: `main` / Folder: `/ (root)`
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で閲覧できます

## 更新
- 毎日、Claudeの定期タスクが `UPDATE.md` に従って `events.js` を更新します。
- 手動で更新したいときは、Claudeに「イベント情報を更新して」と依頼するか、`events.js` を直接編集してください。

## 注意
- 掲載情報は各出典ページに基づきます。開催日・料金・予約要否は変更されることがあるため、お出かけ前に公式サイトで確認してください。
- リポジトリを公開(public)にすると、サイトも誰でも閲覧できます。
